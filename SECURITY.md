# Security Policy

## Reporting a Vulnerability

Please **do not** report security vulnerabilities through public GitHub issues.

Email **security@pass.krd** instead, and include a description, steps to reproduce, the
impact, the sample and versions involved, and a proof of concept if you have one.

We acknowledge receipt within 48 hours and give a fuller response within 7 days.

## Full Security Policy

Supported versions, the security model for the app-to-app authorization flow, redirect
validation and the SDK-side notes are in [docs/SECURITY.md](docs/SECURITY.md). That file is
the one to change; this page exists so GitHub's security tab has something to point at.
